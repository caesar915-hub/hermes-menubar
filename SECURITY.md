# Security Policy

## Supported Versions

We actively support the latest version of Hermes Menu Bar with security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Hermes Menu Bar, please report it responsibly:

1. **Do not create a public GitHub issue** for sensitive vulnerabilities.
2. Email the maintainer or use [GitHub Private Vulnerability Reporting](https://github.com/caesar915-hub/hermes-menubar/security/advisories/new).
3. Include detailed reproduction steps and any relevant log files or environment information.

We aim to acknowledge reports within 48 hours and provide patches promptly.
